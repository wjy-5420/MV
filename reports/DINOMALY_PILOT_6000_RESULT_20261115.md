# Dinomaly 6,000장 소규모 이상 탐지 실험 결과

작성일: 2026-11-15 (KST). 상태: **학습 및 최종 평가 완료(COMPLETED)**.

30개 품목의 정상 train 4,200장으로 원본 Dinomaly 기반 모델을 학습했다. 20 epoch, 16,800회 optimizer 갱신을 완료했으며, validation 기준으로 선택한 epoch 18 모델을 고정 test에 한 번 평가했다.

> 이 실험은 **원본 Dinomaly + 5시점 특징 결합 확장 + 승인 Crop 보존 전처리**를 사용한 OPTIMIZED 조건이다. 수정 없는 공식 기준선이나 논문 수치의 재현 결과로 해석하지 않는다. INP-Former 실험 결과는 포함하지 않는다.

## 1. 목적과 데이터 구성

전체 데이터 학습 전, 30개 품목과 C1~C5 시점의 균형을 유지한 소규모 실행 가능성과 성능을 확인했다.

| 분할 | 정상(OK) | 불량(NG) | 이미지 | 물체 그룹 |
|---|---:|---:|---:|---:|
| Train | 4,200 | 0 | 4,200 | 840 |
| Validation | 450 | 450 | 900 | 180 |
| Test | 450 | 450 | 900 | 180 |
| 합계 | 5,100 | 900 | **6,000** | **1,200** |

- 품목당 200장, 품목·시점당 40장. 물체당 C1~C5 사진 5장이 모두 존재한다.
- 품목별 train은 정상 물체 28개, validation/test는 각각 정상 3개·불량 3개 물체다.
- 시드 `20261115`. 기존 MV_TEAM_DATA_RELEASE_v2의 분할을 유지하고 적격한 물체 그룹 단위로 추출했다.
- 선택 목록 생성 시 알려진 정답 참조 Crop 위험 물체를 제외했다.
- 원본 manifest 151,050장 기준 분할 간 product_id 중복과 저장된 원본 SHA-256 중복은 0건이었다.
- product_id는 선언된 물체 식별자다. 다른 ID 사이의 실제 물리적 동일성까지 독립 검증한 것은 아니다.
- 전체 데이터 실험에서도 기존 분할을 유지해야 하며, 이번 test 물체를 train으로 이동하면 안 된다.

## 2. 모델 및 학습 설정

| 항목 | 설정 |
|---|---|
| 공식 소스 | https://github.com/guojiajeremy/Dinomaly |
| 고정 commit | `1f252be03a918789b19848f0ca37166e7c28dada` |
| 백본 | DINOv2-register ViT-Small/14 (`dinov2reg_vit_small_14`) |
| 학습 방식 | 정상만 사용, 30개 품목 통합 학습 |
| 5시점 결합 | 시점별 압축 특징과 시점 임베딩에 Attention을 적용하고 bottleneck 입력에 잔차 주입 |
| 입력 | 물체 배치 1개 = 사진 5장, 각 392×392 RGB |
| 전처리 | 승인 Crop → 직접 392×392 Resize → ImageNet 정규화 |
| 추가 CenterCrop | 비활성화. 공식 448→392 CenterCrop 조건과 다름 |
| 학습 대상 | bottleneck·decoder·추가 시점 결합. 사전학습 인코더 동결 |
| 파라미터 | 전체 38,177,281 / 학습 대상 16,119,169 |
| 손실 | 공식 hard-mining reconstruction loss |
| Optimizer | 공식 StableAdamW, weight decay 1e-4, AMSGrad 사용 |
| 학습률 | 기준 0.002, 100 step warmup 후 cosine 감소 |
| Gradient clipping | L2 norm 0.1, 비정상 gradient 발생 시 중단 |
| 정밀도 | FP32, AMP 비활성화 |
| 학습량 | 20 epoch × 840배치 = 16,800회 갱신 |
| 장치 | cuda:0, CUDA 사용 불가 시 CPU 대체 없이 오류 |

Dataset·Adapter에서 이미지 전처리를 한 번만 수행하며 공식 Dataset transform을 중복 실행하지 않았다. 시점 간 픽셀 대응을 가정하지 않고 특징을 결합하며 서로 다른 물체의 특징을 섞지 않는다.

| 전체 Run 최대 GPU allocated | 1,590,119,936 bytes, 약 1.48 GiB |
| 전체 Run 최대 GPU reserved | 1,807,745,024 bytes, 약 1.68 GiB |

초기 AMP 실행에서 두 문제가 발생했다.

1. FP16 Linear Attention에서 decoder 특징이 비정상 값이 되어 28회 갱신 후 중단됐다. 해당 Attention을 FP32로 보호했다.
2. 이후 122회 갱신 후 추가 시점 결합 모듈의 scalar gate gradient가 비정상 값이 됐다. 시점 결합을 FP32로 보호하고 Dinomaly의 AMP를 껐다.

비정상 값을 0으로 치환하거나 오류 검사를 끄지 않았다. 수정 후 별도 진단에서 train 전체 840배치를 통과했고, 이후 사용자가 시작한 본 실험에서 20 epoch와 최종 평가를 완료했다. 관련 회귀 검사는 당시 101개 통과했다. 원본 공식 소스 commit은 변경하지 않고 연결 계층과 실행 설정에서 대응했다.

## 4. 체크포인트 선택과 평가 정책

- 매 epoch 전체 validation을 평가했다.
- **클래스별 이미지 AUROC의 평균(macro AUROC)**이 가장 높은 checkpoint를 선택했다. 동률이면 먼저 선택된 epoch를 유지한다.
- 선택 모델: **epoch 18**, validation macro image AUROC **0.825185**.
- 이미지·픽셀·물체 임계값은 해당 모델의 validation 예측으로만 결정하고 test에 고정 적용했다.
- 물체 점수는 같은 물체의 5개 시점 이미지 점수의 최댓값이다. 특징 결합과 최종 점수 집계는 별도 과정이다.
- test는 checkpoint 및 임계값 선택에 사용하지 않고, 선택 완료 후 한 번 평가했다.
- 픽셀 평가는 승인 Crop의 관측 영역에서 수행한다. Crop 밖은 미관측이며 정상 픽셀로 확정하지 않는다.
- 위치 정답 부적격 이미지는 픽셀 평가에서 제외하되 이미지 평가에는 유지한다. 제외 이미지를 정상 마스크로 대체하지 않는다.

## 6. 해석과 한계

- 학습·평가 파이프라인은 완료됐지만 정상 이미지 오탐 265장과 불량 누락 69장이 남아 있다. 이 결과만으로 운영 적용에 충분하다고 판단하지 않는다.
- 물체 AUROC는 사진별 AUROC보다 높지만 평가 단위와 집계 방식이 다르다. 이것만으로 추가 시점 특징 결합 모듈의 효과를 입증할 수 없다.
- 픽셀 AUROC가 높아도 이미지 구분 성능이나 결함 영역의 정밀도가 같은 수준이라는 뜻은 아니다. 픽셀 AP/F1과 오탐·누락을 함께 확인해야 한다.
- 품목·시점당 test가 6장으로 작고 단일 seed 실험이다. 세부 성능의 변동성을 고려해야 한다.
- 일부 픽셀 GT 누락과 기존 Crop 개발 이력이 있어 완전히 독립적인 새 데이터 평가를 보장하지 않는다.
- 원본 독립 이미지 방식과의 대조 실험 및 여러 seed 반복은 아직 수행하지 않았다. 전체 데이터 실험과 후속 모델 비교는 별도다.
